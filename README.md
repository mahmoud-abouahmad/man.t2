# اختبار الاشتقاق الشامل

الصفحة الرئيسية `index.html`: ٦٠ سؤالًا في الاشتقاق وتطبيقاته، مدتها ٩٠ دقيقة. الصفحة `derivatives-60.html` توفر الاختبار نفسه على الرابط السابق. لا تحتوي الصفحة الرئيسية على روابط لاختبارات أخرى. اختبار اللوغاريتم في مستودع مستقل هو `logarethim`.

يمكن تعديل الإجابات قبل التسليم. لا تظهر صحة الإجابة أو الحل أثناء الاختبار، ولا تكشف ألوان خريطة الأسئلة صحة الاختيارات. تُعتمد آخر إجابة محفوظة لكل سؤال، وتظهر العلامة والتقرير والحلول بعد التسليم فقط. يستمر المؤقت أثناء إغلاق الصفحة مع حفظ المحاولة محليًا والتسليم التلقائي عند انتهاء الوقت.

زر واتساب يجهز ملخص النتيجة بعد التسليم إلى رقم المدرس الموجود في `CONFIG.phone`؛ يؤكد الطالب الإرسال داخل واتساب. تعمل الصفحة دون مكتبات خارجية، وتستخدم MathML مضمّنًا لعرض المعادلات.

## التحقق من تأجيل التصحيح

نجح فحص Chromium للأسئلة الستين دون إظهار التصحيح في النصوص أو الألوان أو تسميات إمكانية الوصول، وتغيير الإجابة وحفظها بعد التحديث، وإلغاء التسليم، واحتساب آخر الإجابات بنتيجة ٥٩/٦٠، وإظهار المراجعة بعد التسليم، وتنزيل التقرير، وتجهيز واتساب، والتسليم التلقائي وفق آخر إجابة. لم تظهر أخطاء JavaScript. نتائج الفحص الحالية في `/workspace/scratch/derivatives-60/deferred-results.json` خارج المستودع.
